  文件位置
    .JKui\emu\*.txt
  相对路径、绝对路径（和之前 JJui 可能略有不同，因为调用的函数不同）
    调用程序的路径 与 对应的工作目录
      如果都使用 绝对路径 ，不会有问题。
      如果使用 相对路径：
          首先 JKui 前端的 工作目录：
              如果在 命令行 中运行 JKui ，JKui 的工作目录不变（之前的 JJui 会尝试修改为自身所在的文件夹）；
                注意：换不同的文件夹操作，会找不到原来的配置文件、临时文件等。
              如果 Windows 系统中，鼠标双击运行 或者 选中按回车运行，通常就是当前操作的那个文件夹。
              如果 Windows 系统中，也可以创建一个快捷方式（如果需要的话，快捷方式是可以修改工作目录的）。
          调用程序的工作目录，如果使用相对路径：应相对于 JKui 工作目录。
          调用的程序，如果使用相对路径：应相对于 前面提到的它的 工作目录 。
          调用的程序，如果使用相对路径，并想简写为一个名称，比如 mame.exe ，建议写成 .\mame.exe ，避免歧义
            歧义1：当前文件夹中的 mame.exe
            歧义2：环境变量 PATH 中的 mame.exe
            如果确定 环境变量 PATH 中 没有同名的程序，也是没问题的

1.根据需要设置 命令行工作目录

%cwd% 文件夹路径
  命令行工作目录设置
  如果值为文件夹路径，运行命令行参数时，设它为 工作目录
  如果文件夹不存在，忽略
  应该写在最前方
  
  如果是使用 默认的 mame 模拟器(下面提到的 %mame% 作为命令行指令的第一项)，可以省略，使用默认的 mame 工作目录；
  如果是调用 其它程序，如果不需要切换工作目录，也可以忽略（此时的 工作目录 ，继承 JKui 的工作目录）。

==================================================

2.设置命令行运行参数
   一条命令行的指令，可能有多个片段组成。（各片段通常被空白字符隔开）
   为了写代码简单点，此处，设置的时候，不是整体的设置一整句，而是设置每一个片段。

%mame%
  单独一行
  值为 默认的 mame 模拟器路径，将其添加到命令行指令中
  （通常使用默认的 mame 模拟器用这个，位置需要在命令行指令中的第一项）

%machine%
  单独一行
  值为对应的 machine (游戏名缩写，比如 kof97 ），添加到命令行指令中

%unibios_last%
  单独一行
  使用默认的 mame 模拟器时，查找 uni-bios 信息，如果有，找到最后一个，添加到命令行指令中
    比如 mame -listxml kof97 ，查看信息，然后选择 uni-bios 
    不确定每个版本 bios 名称规则是否一样，可能会影响到查找结果
    一些 neogeo 一类的游戏可能有 uni-bios

%unibios_last_other%
  单独一行
  使用其它 mame 模拟器时，查找 uni-bios 信息，如果有，找到最后一个，添加到命令行指令中
    比如 mame -listxml kof97 ，查看信息，然后选择 uni-bios 
    不确定每个版本 bios 名称规则是否一样，可能会影响到查找结果
    一些 neogeo 一类的游戏可能有 uni-bios

command 指令内容
  为 命令行指令 增加一项

command_suffix 添加的内容
  给前面一项，增加内容
  此处可以使用变量 %machine%（ %machine% ，代表，游戏名缩写，比如 kof97）
    command_suffix %machine%
