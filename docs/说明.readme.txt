以前写过 JJui ，编号加一位，简单取名 JKui 。
使用 QT （ Python 版 QT ）重写一下，感觉可能会好看一点。
都是 QT ，表面看起来和 MxUI 、 M+GUI 很像了。

缺点：
  扫描 roms 功能极其简略（菜单 → 游戏列表 → 刷新游戏列表 ），仅检查 文件夹/文件 是否存在。
  关于 MAME 本身的选项，需自行在 MAME 中设置。
  没有 ips 功能，我对 ips 了解的太少了。
  没有 M1 音乐播放器插件（M+GUI 、MxUI 都有的），M1 这东西多少年没有更新了。
  背景图片需要的话，可以载入外部 qss 文件（类似 css 文件），需要对 qss 文件稍有了解；我已经放了两个 qss ，如果你觉得合适，可以简单替换掉背景图片。

JKui 网址：
  https://github.com/gdicnng/JKui
  https://github.com/gdicnng/JKui/releases

MAME 官方网址：
  https://www.mamedev.org/
  JKui 不是一个独立的程序，是 MAME 的前端，配合 MAME 使用，从 MAME 中读取数据，显示 MAME 的游戏列表，方便选择游戏。

exe 的兼容性：
  python 在新操作系统上打包 生成的 EXE ，不能在旧的操作系统上运行。当前在 github action 上使用的系统版本：Windows2022,OS Version: 10.0.20348 Build 5256 。

当前工作文件夹
  （ 之前的 JJui 与 JKui 不同，JJui 会尝试进入程序所在的文件夹 ）
  JKui 需要的一些文件使用了相对路径，程序运行后，会尝试在 当前工作文件夹 查找需要的 配置文件、临时文件、qss 文件、……等。
  在 Windows 操作系统中，鼠标双击打开 .exe 程序，当前工作文件夹 应该就是操作时所在的文件夹。
  在 Windows 操作系统中，如果经常使用，也可以创建一个快捷方式，放在桌面上。快捷方式 可以 查看属性，如有需要也很方便修改 工作文件夹（正常来说不需要改的）。
  用 命令行 打开的话，要特别注意当前工作文件夹，当前工作文件夹不对，程序 找不到需要的文件。
  
  比如下面这些使用相对路径的文件：
    .JKui\JKui.ini
       此文件用于保存设置信息
    .JKui\cache_data.pickle
       此文件用于保存游戏列表的内容
       初始化完成以后，此文件不会再改变
    .JKui\cache_available.pickle
       此文件用于保存拥有列表
    .JKui\extra.db
       此数据库文件用于保存 周边文档 的内容。
       注：菜单中 【 周边 】 → 【 重新加载周边文档 】。手动操作，读取内容到数据库，然后才能显示周边文档信息。
       注：如果需要更新文档内容，再次手动点击一下。

程序启动时需要选择 mame 程序所在的路径 ；mame 工作文件夹 可以留空不设置让JKui自行判断（可以留空，但不可以乱填）。
  可以使用 绝对路径 或 相对路径 。相对路径的话 应当 相对于 当前工作文件夹。
  第一次启动需要多等一小会儿，从 mame 中提取游戏列表数据。
  读取数据完成后，可以点击 目录列表，游戏列表处就会显示对应的内容。

关闭程序时，自动保存相关设置。
  如果程序意外关闭的话，设置选项，可能不会正确保存。

【 Fusion 】
    运行的时候，菜单中选： 【 UI 】 → 【 style 】 → 【 Fusion 】 。
    我测试时用的这个。
    选其它的，视觉效果可能略有差异；并且，有些选项，可能没有效果。

背景图片的话：
  背景图片在下层，文字在上层；中间层设为透明或半透明，可以看到背景图片；
  半透明如果能调整的好一些，能让文字显示得更清晰一些，我设置的两个 qss ，放在了 qss 文件夹里。
  如果本身是 白底黑字，可以选择 【 UI 】 → 【 qss 】 → 测试背景图片2 ；
  如果本身是 黑底白字，可以选择 【 UI 】 → 【 qss 】 → 测试背景图片1 。
  （我电脑上 ：qt5 ，默认是 白底黑字；qt6 ，windows 11 操作系统如果选主题颜色不同显示可能不一样，白底黑字 或 黑底白字 ）
  如果懂 qss ，可以自己设置。
  如果不懂 qss ，可以简单替换 qss 文件夹 中对应的图片，不过只是替换图片，不调整其它选项，可能视觉效果不佳。

中文游戏列表
  菜单 → 语言 → 游戏列表翻译文件 → 设置对应的文件
  资源：https://bbs.xqemu.cn/forum.php?mod=viewthread&tid=1591
  文本文件，字符编码为 utf-8 ，如果是其它编码，自己在文本编辑器中转换一下。
  文件扩展名，一般是 .lst
  文件内容格式：
    每一行以英文名缩写开头，以制表符分隔（ Tab 键 可输入制表符），后面接上翻译的内容。
    如果一行内有多个制表符，第二个制表符以及后面的内容 将被 JKui 忽略

第三方目录 以及 自定义目录
  菜单 → 周边路径 ，设置 folders 选项，文件夹的位置。
  菜单 → 周边 → 显示 隐藏 窗口，可以选择 显示 、隐藏。
  菜单栏下面的工具栏，等于号的图标，同样的功能，显示 显示 隐藏 窗口。
  
  如果需要在自定义目录中 添加 删除 游戏：
   菜单 → 目录列表 → 编辑目录。开启这个选项，才可以编辑。修改完成后，记得点标保存。
   菜单 → 游戏列表 → 多选模式（仅前三个列表有多选功能）。开启多选模式，编辑时可能会更方便一些。
  
  如果有不想被修改的文件，可以把对应的文件属性设为只读。以免误操作修改了内容。
  
  文件名中不要包含英文分号，配置文件记录置顶项目时，以分号分隔

周边文档：
  菜单 → 周边路径 ，设置对应文件的位置。
  菜单 → 周边 → 显示 隐藏 窗口，选择要显示的文档类型。
  菜单中 【 周边 】 → 【 重新加载周边文档 】。需要手动点一下载入，读取到数据库后，才能显示。
  中文出招表字体，建议选择等宽字体，而且是那种 两个英文字符的宽度 正好 等于  一个中文字符的宽度，这样文本排列会显示得更整齐一些，比如 宋体、楷体 等，可以自己测试，。

周边图片：
  菜单 → 周边路径 ，设置对应文件的位置。
  菜单 → 周边 → 显示 隐藏 窗口，选择要显示的图片类型。
  建议使用 zip 压缩包格式的，毕竟下载下来的资源都是 zip 压缩包格式的。
  如果设置的 图片的 文件夹 路径，这个会优先使用。
  不使用 文件夹 里的图片，建议 把 设置里的 图片的 文件夹路径 删除清空，因为每次切换图片，都会优先检测文件夹中的图片文件是否存在。
  zip 中的 文件名，要求小写
  图片为 *.png 文件

图标：
  菜单 → 周边路径 ，图标，设置对应 .zip 文件的位置。
  设置了 .zip 文件以后，程序启动的时候，会读取 .zip 中的内容到内存里，会多花一点时间。
  菜单 → 游戏列表 → 选择 使用图标

游戏列表5 ：QListView 做的，图标列表。
  菜单 → 设置 → 图标大小，设置对应的 图标大小、文字区域 宽度 高度 等
  菜单 → 周边路径 ，设置图标文件的位置，（设置完需要关闭程序重新打开）

游戏列表6 ：QListView 做的，图片列表。
  菜单 → 周边路径 ，设置图片文件的位置：图片_zip_路径_序号，设置最后一个。
    文件为 zip 文件，内部为 *.png 文件。文件名要求小写。
    设置完成后，切换其它样式的列表，再次切换到 图片 列表，会载入 .zip 文件。
  菜单 → 设置 → 图片大小，设置 图片的宽度、高度，文字区域的高度（文字区域的宽度与图片宽度一样）

多选，勾选
  仅前面三个列表添加了此功能
  该功能，配合 目录 的 编辑功能使用，方便编辑 自定义目录。
    1. 菜单，目录列表，启用编辑功能。
    2. 菜单，游戏列表，启用多选（勾选）功能。
    注意：切换游戏列表时，已经勾选的项目，本身没有取消。
    多选操作方式：
        鼠标点击勾选方框：可以 选择/取消选择 单个项目
        Ctrl + A ：（之前会清空选项）勾选当前表格所有项
        Alt  + A ：清空所有勾选项
        Ctrl + X ：（之前会清空选项）对当前表格所有项目，反转 勾选状态
        Ctrl + 鼠标点击：（此时不要点击在勾选方框上）被点击的那一行，反转 勾选状态
        Ctrl + 鼠标点击按住不放，拖动：移动范围，反转 勾选状态；感觉拖动快的话，有可能会漏选
        鼠标点击一行，然后 Shift + 鼠标点击另一行：前一次选中的行 与 后一次点击的行，两者之间，反转 勾选状态

菜单 → 游戏列表 → 编辑（仅 游戏名(译) 这一列）
  编辑完了，记得点击它下面的保存选项
  图标列表、图片列表，无此功能；仅在文字列表中操作。
