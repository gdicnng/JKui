以前写过 JJui ，编号加一位，简单取名 JKui 。
使用 QT （ Python 版 QT ）重写一下，感觉可能会好看一点。
都是 QT ，表面看起来和 MxUI 、 M+GUI 很像了。

JKui 网址：
  https://github.com/gdicnng/JKui
  https://github.com/gdicnng/JKui/releases

MAME 官方网址：
  https://www.mamedev.org/
  JKui 不是一个独立的程序，是 MAME 的前端，配合 MAME 使用，从 MAME 中读取数据，显示 MAME 的游戏列表，方便选择游戏。

exe 的兼容性：
  python 在新操作系统上打包 生成的 EXE ，不能在旧的操作系统上运行。当前在 github action 上使用的系统版本：Windows2022,OS Version: 10.0.20348 Build 5256 。

免安装版本 1：
  python-3.13-embed-win64_PySide6.7z
  免安装版本 python ，不打包 exe 版本，解压缩以后，双击 run_Jkui.bat 文件，运行。
  python 3.13 + Qt6
  兼容性，估计需要 windows10 2019 以上。

免安装版本 2：
  python-3.8.10-embed-win32_PyQt5.7z
  免安装版本 python ，不打包 exe 版本，解压缩以后，双击 run_Jkui.bat 文件，运行。
  python 3.8 + Qt5
  应该可以在 win7 上运行
  ( win7sp1 原始光盘安装的 纯净的、还没有打补丁的，应该用不了 )
  不过我写代码的时候用的新版本，老版本未做充分的测试，这个有可能会遇到更多的问题，如有遇问题的话，可以告诉我。

运行的时候，菜单中选： 【 UI 】 → 【 style 】 → 【 Fusion 】 。我也选这个，选其它的，视觉效果可能略有差异。

背景图片的话：
  背景图片在下层，文字在上层；中间层设为透明或半透明，可以看到背景图片；
  半透明如果能调整的好一些，能让文字显示得更清晰一些，我调的两个 qss 效果，放在了 qss 文件夹里。
  如果本身是 白底黑字，可以选择 【 UI 】 → 【 qss 】 → 测试背景图片2 ；
  如果本身是 黑底白字，可以选择 【 UI 】 → 【 qss 】 → 测试背景图片1  。
  可以替换 qss 文件夹 中对应的图片，不过简单替换，不调整其它选项，可能视觉效果不佳。

第三方目录 以及 自定义目录
  菜单 → 周边路径 ，设置 folders 选项，文件夹的位置。
  菜单 → 周边 → 显示 隐藏 窗口，可以选择 显示 、隐藏。
  菜单栏下面的工具栏，等于号的图标，同样的功能，显示 显示 隐藏 窗口。
  
  如果需要在自定义目录中 添加 删除 游戏：
   菜单 → 目录列表 → 编辑目录。开启这个选项，才可以编辑。修改完成后，记得点标保存。
   菜单 → 游戏列表 → 多选模式。开启多选模式，或许更方便一些。
  
  如果有不想被修改的文件，可以把对应的文件属性设为只读。以免误操作修改了内容。
  
  文件名中不要包含英文分号，配置文件记录置顶项目时，以分号分隔


周边文档：
  菜单 → 周边路径 ，设置对应文件的位置。
  菜单 → 周边 → 显示 隐藏 窗口，选择要显示的文档类型。
  菜单中 【 周边 】 → 【 重新加载周边文档 】。需要手动点一下载入，读取到数据库后，才能显示。
  中文出招表字体，建议选择等宽字体，而且是那种 两个英文字符的宽度 正好 等于  一个中文字符的宽度，这样文本排列会显示得更整齐一些，比如 宋体、楷体 等，可以自己测试，。

周边图片：
  菜单 → 周边路径 ，设置对应文件的位置。
  菜单 → 周边 → 显示 隐藏 窗口，选择要显示的图片类型。
  建议使用 zip 压缩包格式的，毕竟下载下来的资源都是 zip 压缩包格式的。
  如果设置的 图片的 文件夹 路径，这个会优先使用。
  不使用 文件夹 里的图片，建议 把 设置里的 图片的 文件夹路径 删除清空，因为每次切换图片，都会优先检测文件夹中的图片文件是否存在。
  zip 中的 文件名，要求小写
  图片为 *.png 文件

游戏列表1：QTableView 做的，单层列表
游戏列表2：QTableView 做的，伪双层列表 ，不可收缩
游戏列表3：QTableView 做的，伪双层树状列表，可以点击展开、收缩。（原生的树状列表 QTreeView ，初始化有点慢，补充了这个列表）
游戏列表4：QTreeView 做的，树状列表，可以点击展开、收缩。
  感觉初始化需要时间，尤其列表数量多的话，切换列表时明显要慢一些。
游戏列表5: QListView 做的，图标列表。
  设置了统一大小，刚开始的单元格大小，会统一后面的显示。
  图标都统一转换了一样的大小，但文字没有，一开始显示的文字如果比图标长，单元格可能会显示得太宽。
  菜单 → 周边路径 ，设置图标文件的位置，文件为 zip 文件，其中为 *.ico 文件。文件名要求小写。
游戏列表6: QListView 做的，图片列表。
  设置了统一大小，刚开始的单元格大小，会统一后面的显示。
  图片都统一转换了一样的大小，但文字没有，一开始显示的文字如果比图片长，单元格可能会显示得太宽。
  菜单 → 周边路径 ，设置图片文件的位置，图片_zip_路径_序号，设置最后一个。文件为 zip 文件，其中为 *.png 文件。文件名要求小写。
目录列表： QTreeView 做的。

多选，勾选
  仅前面三个列表添加了此功能
  该功能，用于配合 目录 的 编辑功能使用，方便编辑 自定义目录。
   1. 菜单，目录列表，启用编辑功能。
   2. 菜单，游戏列表，启用多选（勾选）功能。
   注意：切换游戏列表时，已经勾选的项目，本身没有取消。
     鼠标点击点击勾选方框：可以 选择/取消选择 单个项目
     Ctrl + A ：（之前会清空选项）勾选当前表格所有项
     Alt  + A ：清空所有勾选项
     Ctrl + X ：（之前会清空选项）对当前表格所有项目，反转 勾选状态
     Ctrl + 鼠标点击：（此时不要点击在方框上）点击的行，反转 勾选状态
     Ctrl + 鼠标点击按住不放，拖动：移动范围，反转 勾选状态；感觉拖动快的话，可能会漏选
     选中一行，然后 Shift + 鼠标点击另一行：前一次选中的行 与 后一次点击的行，两者之间，反转 勾选状态

图标：
  菜单 → 周边路径 ，图标，设置对应 .zip 文件的位置。
  设置了 .zip 文件以后，程序启动的时候，会读取 .zip 中的内容到内存里，会多花一点时间。
  菜单 → 游戏列表 → 选择 使用图标
